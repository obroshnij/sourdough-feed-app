# Audio direction

Owner: sound-designer. Status: Phase 4, first full set (D-056). 31 files, 1,930 KB of the 2,048 KB budget, all synthesized, every check in `verify_audio.py` passing. Nobody has listened to them yet: every judgment below comes from measurements (§4), so the user's play session on the iPhone is the real test.

## 1. Mood

**A calm kitchen in the afternoon, heard from close up.** Quiet, warm and tactile: wood, glass, a steel spoon, thick paste, a little water, soft air.

- Never cartoony, never loud, never a jingle. No music in the MVP: the room tone and the jar are the score.
- **Sound adds nothing the screen doesn't show.** Status never depends on sound (CLAUDE.md rule 7), so a player with the sound off misses nothing.
- **Sound never says what the sim didn't produce** (hard rule 2, narrative §3.1). Bubble pops play only for pops the view draws. The smell swell is the same for every smell, so it never hints at the result. No mood sounds.
- **Mold and discard are subdued and never comic.** No falling "sad" interval, no minor-key sting, no wobble, no cartoon splat.
- **It must survive a phone speaker.** An iPhone speaker loses most of what is under about 250 Hz, so every sound keeps its character above that (the `<250` column in §4).

## 2. How the sounds are made

Every file is generated by a script in `art/audio/scripts/`: Python standard library plus numpy, seeded, no recordings and no samples (D-056). Randomness comes from a counter-based SplitMix64 in `audio_lib.py`, so it never depends on numpy's Generator streams.

| Script | Builds | How |
|---|---|---|
| `audio_lib.py` | (shared) | Filters (RBJ biquads applied through the FFT, a time-varying state-variable filter), modal resonators struck by a Gaussian contact, stick-slip scrapes, bubbles (a damped tone whose pitch rises, after van den Doel), poured streams, a felt-mallet note, the BS.1770 meter, WAV and Ogg writers |
| `bubbles.py` | `bubble_pop_1` to `_6` | Bubble tone plus a duller paste body and a faint skin tick |
| `jar.py` | `glass_tink`, `starter_poke`, `lid_lift`, `lid_set`, `band_snap` | The jar's glass modes (about 1.48, 4.19 and 8.0 kHz, each a detuned pair), the oak lid's modes, a rubber thup |
| `feed.py` | `feed_hooch`, `feed_discard`, `feed_scoop`, `feed_pour`, `feed_stir`, `starter_new` | Scrapes, flour crunch and puff, streams with bubble fizz, paste squelches, a spoonful landing in a clean jar |
| `smell.py` | `smell_swell` | A bandpassed breath that swells, with a very faint open fifth under it |
| `ui.py` | `ui_tap`, `ui_tick`, `ui_toggle_on`, `ui_toggle_off`, `sheet_open`, `sheet_close` | Woody clicks; air that follows the sheet's easing |
| `chimes.py` | `event_chime`, `event_chime_soft`, `status_tick` | Felt-mallet notes, G4 and D5 |
| `mold.py` | `mold_found`, `mold_discard` | A low open-fifth swell; scrapes, a drop and a rinse |
| `room_tone.py` | `room_day`, `room_night` | Shaped noise made in the frequency domain, so the loop is seamless |
| `verify_audio.py` | (check) | Measures every file (§4) and fails on any rule in §4 |
| `build_all.py` | everything | Runs all of the above, then the check |

```bash
python3 -I art/audio/scripts/build_all.py      # about 8 s, ends "RESULT: PASS", exit 0
python3 -I art/audio/scripts/verify_audio.py   # check only, about 3 s
python3 -I art/audio/scripts/feed.py           # one family
```

- **Byte for byte:** rebuilding gave the same SHA-256 for all 31 files on this Mac (Python 3.15.2, numpy 2.5.4, ffmpeg 9.0.2). Another CPU or numpy build may round a few samples differently; `verify_audio.py` still passes then.
- **The room tone needs ffmpeg** for the Ogg step. ffmpeg's own Vorbis encoder is marked experimental and takes stereo only (there is no libvorbis on this Mac). It is deterministic with the bit-exact flags. At quality 3 the decoded loops stay within 0.3 dB of the source below 1 kHz and within 2.3 dB above 2 kHz, with the same frame-to-frame variation. Quality 1 left holes above 8 kHz and quality 0 decoded to silence, so 3 it is.
- **Loop lengths are multiples of 1024 samples:** day 516 × 1024 (11.98 s), night 344 × 1024 (7.99 s, stiller, so a shorter loop hides as well). A 12.0 s loop decoded 16 samples longer, padded with near-silence, which would tick at every wrap. Multiples of 1024 decode to the exact length.
- **Vorbis adds its own noise.** Decoded against the source, the coding error is about 14 dB under the signal. On noise that is a different noise with the same spectrum (the band levels two bullets up), so it isn't heard as damage. It does make the wrap step random: `verify_audio.py` fails it only if it is larger than 99.9% of the file's steps.
- **No downloads so far.** `art/audio/LICENSES.md` records the provenance and will list any approved CC0 file.

## 4. Formats, loudness and the check

| Rule | Value |
|---|---|
| One-shots | WAV, 16-bit PCM, mono, 44.1 kHz |
| Loops longer than 2 s | Ogg Vorbis, stereo, 44.1 kHz, quality 3 |
| Peaks | Sample peak and 4x true peak at or below -3 dBFS (the generator caps true peak at -3.2) |
| Edges | Every one-shot starts and ends on silence (fade-in 0.5 to 20 ms, fade-out 15 to 300 ms). Loops have no fades: they are seamless, and the player fades them |
| Set size | Under 2 MB (now 1,930 KB). Godot's QOA import makes the shipped copy smaller still |

**Loudness** follows ITU-R BS.1770-4 (K-weighting, 400 ms blocks, gating), with mono measured as one channel. One-shots are judged by their loudest 400 ms window, loops by integrated loudness. My meter matched ffmpeg's `ebur128` filter to 0.1 LU, and true peak to 0.1 dB, on 6 files.

**The ladder.** The role sheet asks for about -20 LUFS on short effects. The feed sounds sit at -21. Everything else is deliberately lower, by how often it plays and how much it should draw the ear:

| Level | Sounds |
|---|---|
| -21 to -23 | The feed sequence, smell, the event chime, the mold moments |
| -24 to -27 | Lid, band, glass tap, poke, new starter, info chime |
| -30 to -35 | Status tick, UI clicks, sheet air, bubble pops. A 400 ms window under-reads a 25 ms click by about 6 dB, so these sound closer to -26 than the number says |
| -38 / -44 int. | Room tone, day and night |

## 5. Mixing rules (for T2)

**Buses.** Master, then `Room`, `Sfx` and `Ui` under it, all at 0 dB. The mix is baked into the files, so every player starts at `volume_db = 0` unless this doc says otherwise. Godot's `normalize` import option stays off.

| Rule | Spec |
|---|---|
| Voices | `Room`: 2 players (day and night). `Sfx`: a pool of 6. `Ui`: a pool of 2. When a pool is full, the oldest voice stops (40 ms fade). At most 2 bubble pops at once |
| Bubble pops off | While a sheet is open, during the feed sequence, the smell moment and the time-lapse. They are ambient and never compete with an action |
| Ducking | `Room` drops 3 dB during the smell moment and while the `mold_found` sheet is open, with 300 ms ramps |
| Skip | When the feed sequence is skipped, fade every playing feed sound out over 80 ms. `band_snap` still plays with the final firm haptic |
| Day and night | `Room` follows the same night factor as the lighting (`Session.get_night_factor()`, or the frame's factor during the time-lapse). Equal power: day gain `cos(n·π/2)`, night gain `sin(n·π/2)`. Updating once a second is enough |
| Start | Room fades in over 2 s after `session_ready` |
| Background | On pause, fade everything out in 150 ms and stop. On `resumed`, the room fades back in over 1.5 s |
| Sound off | `SettingsStore.sound == false` mutes Master (`AudioServer.set_bus_mute`). `master_volume` (0 to 1, default 1.0) sets Master `volume_db = linear_to_db(v)`; 0 mutes. On the slider's release, `Bus.feedback(&"preview")` plays `glass_tink` at the new level (ux §14.3) |
| Haptics | Independent. Haptics off never silences a sound, sound off never stops a haptic (T1's `Haptics.play`) |
| Reduce motion | Audio stays the same. What changes follows the shorter beats: no feed steps play except `settle` (so only `band_snap`), and `smell_swell` fades at the 600 ms `smell_moment_finished` |
| Repeats | `glass_tink` and `ui_tap` cycle `pitch_scale` through 1.0, 1.03, 0.97 so quick repeats don't sound mechanical. Nothing else is pitched |
| Space | All players are plain `AudioStreamPlayer` (not 3D). The jar is always center screen |

- **Feed and discard timing changes for T2** (agreed with art-director, who writes them into art-direction §8 and §9). From reading the view code (not run), today's `FeedMoment` differs:
  - **Lid:** lifts at the first beat that reaches into the jar (`hooch` if present, else `discard`), not at `scoop`, and lowers at `settle`. Same motion (8 mm, 10 degrees, 0.5 s).
  - **Flour dust:** starts at `scoop` + 0.45 s, where `feed_scoop.wav` lands the flour, not at `pour`. `pour` is water.
  - **Band snap:** on T1's new `settle` step, not on the next `state_changed` or the 8 s timeout.
  - **Discard ceremony** (art-director's visuals, matched to `mold_discard.wav`): scrape and level drop 0 to 0.62 s, empty at the drop 0.72 s, the rinse clears the glass 1.0 to 2.25 s, clean empty jar at 2.3 s. Reduce motion: a 0.4 s crossfade to the clean jar, and the sound plays in full.

## 8. Open items

- **iOS audio session.** `audio/general/ios/session_category = Ambient` and `mix_with_others = true` in `project.godot` (T1, requested; ux-designer agrees): the ring/silent switch then mutes the game, and the player's own music keeps playing. Both names and the Ambient option are in the 4.7.2 binary's strings; the behavior needs the iPhone.
- **Default volume 100%,** not ux's proposed 80%. The set is already mixed quiet, so 80% (about -1.9 dB) would only make it quieter than the player's other apps.
- **A CC0 room tone recording** would add life (distant traffic, a far bird) that noise can't. Not needed for the MVP; ask first if wanted (D-056).
- **A better Vorbis encoder** (libvorbis's `oggenc`) would allow mono loops at about half the size. Installing it needs the director's approval.
- **Per-place room tones** (a fridge hum, a warm oven) are P2 with the other environments.
- **The listening pass.** Levels and timbres are set by measurement only. The play session on the iPhone decides; any change is a parameter in one script.
